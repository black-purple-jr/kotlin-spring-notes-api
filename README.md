# Spring Boot notes API

# Overview

This is a Spring Boot and Kotlin Rest API that saves, retrieves and deletes notes from a non-relational database, this is the first API I've ever built as a seperate service, so it may contain a lot of architectural flaws.

# Features

- Secure authentication using JWT (JSON Web Token)
- Adding, getting and deleting notes

# Technology Used

- Kotlin
- Spring Boot
- MongoDB
